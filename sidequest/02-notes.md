# 支线 S2《神经元与 XOR》· 讲义与追问实录

> 对应代码:`sidequest/02_learning_function.py` | 状态:✅ 完课 2026-10-22(四幕全清,考题双交卷)

## 一句话

神经元 = **加权求和(S1 的直线)+ 激活函数(掰弯)**;单个神经元是一条直边,切不开 XOR;
两层 + 非线性就能切——而把激活换成恒等函数,两层当场坍缩回一层。**非线性是网络的灵魂。**

## 四幕实录(真实输出)

1. **神经元解剖**:同权重 (1,1),偏置 b=0 输出 `x1+x2`(OR 雏形);b=-1 变 AND 门——偏置 = 门槛;
2. **死局**:单神经元从零老实训 6000 步,卡在 2/4(w 收敛到 −1.5/−1.5)。四个点在正方形四角、对角同类,一条直边(=半个平面)物理上不可能只留两个对角。**1969 年 Minsky/Papert《Perceptrons》以此判死单层,神经网络寒冬十五年**;
3. **胜利与反证**:两层 + ReLU,loss → 0.000000,4/4;同样两层、激活换恒等函数,loss 死守 0.25(=全猜 0.5)。展开 `a·(w11x1+w12x2+b1)+b·(w21x1+…)+c`,同类项合并后 x1、x2 的系数仍是常数——**线性套线性还是线性,两层=一层**;
4. **表示学习**:隐层把 (0,1) 和 (1,0) 折到相近表示——网络自己发明『恰好一个开』的中间概念。大模型几十亿参数的"特征"就是这玩意儿的豪华版。

## 教师调试实录(两轮翻车,比四幕更值钱)

- **第一轮:训练纹丝不动**(预测全 0.5,loss 死守 0.25)。诊断:初始权重下隐层 ReLU 几乎全灭(实测 4 个输入里 3 个全 0)→ **死区问题**:激活输出全零时,梯度传不到第一层,整个网络失联;
- **第二轮:lr=2.0 直接爆炸**(loss 冲到 4.5×10²³,S1 那个 2.7e26 的亲戚);lr=1.0 又塌回全负;
- **解法:重掷种子**。30 个 seed 里 6 个能逃出死区(≈20% 成功率),挑 seed=21。**这就是真实训练日常:不收敛时先怀疑死区/坏初始化,换个种子重跑是正经操作**(大公司炼丹师嘴里的"玄学",一大半是这个);
- 数值版教训:9 个旋钮 × 每步 2 次全量前向,数值梯度已开始"贵"——S3 手推链式法则的动机挂出。

### 三座动机桥(进正题前先答「为什么要学这个」)

1. **任务换频道**:S1 是回归(拟合数字),本站是分类(下判断)。「切开」= 给输入空间染色、划决策边界 = 对 4 条数据各下对判断——不是数学游戏,是换了种作业题型;
2. **单层切不开的本质**:XOR 里 x1 的影响方向随 x2 翻转(同样把 x1 调大,有时加分有时减分),「每个输入独立打分再相加」的架构装不下这种联动;AND 四个点方向一致,是「单层能做」的对照组;
3. **历史线**:1943 McCulloch-Pitts → 1949 Hebb → 1958 感知机 → 1969 Minsky《Perceptrons》判死单层(寒冬十五年)→ 1986 反向传播翻案 → 2012 AlexNet 燃爆。

### 追问实录(金矿区)

1. **「AND/XOR/偏置 b 有什么用?」** → 仪器论:XOR 不是刁难,是**针对「单层架构」的最小可复现 bug 报告**——四条数据、一条直边,物理上切不开;AND 是「能做」方向的对照刻度;偏置 = 门槛(b=−θ 自带生物血统:神经元的点燃阈值)。
2. **「神经元是数学概念还是生物概念?」** → **数学概念穿生物戏服**。1943 年 McCulloch-Pitts 借神经元之壳包装逻辑门,b = −θ(阈值)是仅存的生物遗产;现代 AI 早已去生物化,「神经元」只剩历史命名。

### 第二幕新料(实验数据)

- **拔河手推**:第一轮梯度扫描逐步手推,亲眼看到隐层 ReLU 输出全零 → 梯度传不回第一层 → **死区冰冻**(给首讲「训练纹丝不动」补上了手推证据链);
- **恒等激活控制组**:同样 lr=0.5,ReLU 版能学,恒等版 loss 爆到 **5.4×10⁷** → **学习率不跨模型通用**,换架构要重新调;
- **0.25 的来历手推**:对全 0.5 的预测,最优解是 a=0、c=0.5——输出层干脆躺平,只输出先验概率,「全猜 0.5」的投降书。

## 复盘(本站带走的三句话)

- 神经元 = 加权求和 + 激活;偏置 = 门槛;ReLU = 最小号的弯;
- 单元(直边)→ 层(折线)→ 网络(任意形状):**深度 = 把简单弯折叠成复杂边界**;
- 死区与坏种子是训练日常的一部分:**"调不动了"先换种子,再查学习率,最后才怀疑人生**。

### 本轮追问金矿(比首讲更值钱)

1. **「偏置 b 和 ReLU 什么关系?」** → 流水线前后两站:score = Σw·x + b(b 画及格线),ReLU(score) 把不及格的归零(折叠)。分工:b 管画线,ReLU 管折叠。
2. **「为什么要它符合 XOR 的逻辑?有现实对应吗?」** → 没有现实逼人算 XOR;它是 Minsky 挑出的最小反例。现实对应 = 「x1 加分还是减分取决于 x2」:夏天加冰爽、冬天加冰惨;有新消息时推送贴心、没有时是骚扰。真实数据(图像、语言)全是这种联动的豪华版。
3. **「神经元为什么不能是一条曲线?」**(天马行空实则正经)→ 边画在 score=0 处,一次方等值线必为直线,ReLU 折的是输出值不折分界线。手工塞曲线特征(x1·x2 交叉项)真的能解 XOR——这条路的尽头是 SVM 核方法;败在「手工」二字,特征一多设计不动。多层方案反着来:堆笨直线、让梯度下降自己学出曲线。分胜负的是规模。
4. **「01 和 10 并没有挨得很近」**(学员抓错,已更正进代码打印)→ 对 SEED=21 的解,「折到相近」不成立:(0,1)→(1.03,0)、(1,0)→(0,1.08),相距 1.49。该解的真实结构 = 双方向探测器:h1 ≈ −x1+x2、h2 ≈ x1−x2,读出 a≈(1.14,1.09,−0.18) 相加。不变的的本质:**隐层把「直刀切不开」折叠成「读出层一条直边切得开」(不可分→可分)**。「折到相近」只是某些解的长相——学员实测 SEED=10 恰好学出该款,坐实解不唯一。

### 考题交卷实录

- **Q1(0.5 的来历)**:MSE 下最优常数预测 = 标签均值(0,1,1,0 → 0.5);手算对照 f=0.5x1+0.5x2 的 loss=0.375 更差。XOR 与 x1、x2 零相关,看谁都没信息量,猜基率是唯一不吃亏的策略——恒等版输出层 a→0、c→0.5 是算尽所有直线后的投降书,与 P0.1 贪心自锁同属「能力到顶的躺平」。
- **Q2(死区现场)**:SEED=0 实跑 loss 卡 0.25(死区亲见);SEED=10 loss=0 且隐层 (0,1)/(1,0) 相近——一句话交卷:碰上死区,先换种子。

## 复盘(完课版带走五句话)

- 神经元 = 加权求和 + 激活;b = 门槛;ReLU = 最小号的弯;b 画线、ReLU 折叠;
- 单元(直边)→ 层(折线)→ 网络(任意形状):深度 = 把简单弯折叠成复杂边界;
- 非线性是唯一的魔法,层数本身不值钱(恒等反证:两层坍缩一层,全猜 0.5);
- 隐层的本职 = 不可分 → 可分;解不唯一,长相随种子(21 双探测器 / 10 折到相近);
- 死区与坏种子是训练日常:调不动先换种子,再查学习率,最后才怀疑人生。
