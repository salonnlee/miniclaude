## S1 核心概念(三个零件)

1. **模型 = 带旋钮的函数** `f(x) = w*x + b`。旋钮 w、b 就是「参数」;换旋钮值 = 换一个函数。
   JS 视角:一个吃 config 的纯函数。
2. **loss = 一个数字的「错得多离谱」评分**。均方误差:平方去负号、离谱重罚。
   JS 视角:CI 的红色失败数——训练 = 自动改 config 把 CI 调绿。
3. **数值梯度 = 拿尺子量坡度**:`(loss(w+H) − loss(w−H)) / 2H`,H = 1e-5。
   这就是「斜率」的定义本身,不是简化。梯度符号告诉你:旋钮该往哪边拧,loss 才会降。
4. **训练 = 反复下坡**:`w -= LR * grad`(梯度为正→调小,为负→调大,始终朝下坡)。
   学习率 LR = 每步拧多大。

## 实验记录(真实)

```
起点    | w 0.000 b 0.000 | loss 9.6126   ← 一无所知
step  40 | w 1.949 b 1.034 | loss 0.004082
step 200 | w 1.998 b 0.979 | loss 0.003215
真相:y = 2x + 1(带 ±0.1 噪声)→ 机器学到 1.998x + 0.979,残差来自噪声,理论不可再降
```

两百次「量坡 + 下坡」,机器自己摸出了造数据的隐藏规律。

## 复盘(本站带走的三句话)

- 「学习」= 调参数让 loss 变小,没有任何神秘成分;
- 梯度方向 = 下坡方向,大小 = 坡有多陡;
- 数据决定它能学到什么,训练只是找到那条最贴合数据的旋钮组合。
