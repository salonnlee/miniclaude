## S1 核心概念(三个零件)

1. **模型 = 带旋钮的函数** `f(x) = w*x + b`。旋钮 w、b 就是「参数」;换旋钮值 = 换一个函数。
   JS 视角:一个吃 config 的纯函数。
2. **loss = 一个数字的「错得多离谱」评分**。均方误差:平方去负号、离谱重罚。
   JS 视角:CI 的红色失败数——训练 = 自动改 config 把 CI 调绿。
3. **数值梯度 = 拿尺子量坡度**:`(loss(w+H) − loss(w−H)) / 2H`,H = 1e-5。
   这就是「斜率」的定义本身,不是简化。梯度符号告诉你:旋钮该往哪边拧,loss 才会降。
4. **训练 = 反复下坡**:`w -= LR * grad`(梯度为正→调小,为负→调大,始终朝下坡)。
   学习率 LR = 每步拧多大。

## 实验记录(真实)

```
起点    | w 0.000 b 0.000 | loss 9.6126   ← 一无所知
step  40 | w 1.949 b 1.034 | loss 0.004082
step 200 | w 1.998 b 0.979 | loss 0.003215
真相:y = 2x + 1(带 ±0.1 噪声)→ 机器学到 1.998x + 0.979,残差来自噪声,理论不可再降
```

两百次「量坡 + 下坡」,机器自己摸出了造数据的隐藏规律。

## 考题(✅ 学员已交卷,2026-10-19)

- **Q1(口头)**:梯度 −6.5 时 w 变大还是变小? → **满分**。学员答:`w -= LR·(-6.5) = w + LR·6.5`,变大;并给出完整机理——梯度为负说明"拧大能让 loss 降",该顺势拧大;为正则往回拧;`w -= LR·grad` 恒朝下坡逼近。教师补一刀:−6.5 里的 **6.5 还是坡的陡度**(每拧 1 单位 w,loss 约降 6.5),方向和陡度都免费送。
- **Q2(动手)**:真相换 `y = -3x + 5` 还摸得出来吗? → **摸得出来**(学员判断正确;按课程纪律补跑了完整数据):200 步学到 `w=-2.996, b=4.973`,loss 0.0032——**斜率正负无关,负坡照样下**。
- **瞎折腾区(补跑)**:LR = 10.0 时 step 0 就从 w=0 飞到 21.4、loss 3982;step 50 涨到 **loss 2.7×10²⁶**(数值上溢后卡死)——学员口中的"全乱套",数据版叫**梯度爆炸/发散**:步子大于谷底宽度,每步都跨到对面更高的坡上,越蹦越高。0.2 的 Q2(lr=5.0)会再见,届时是 4489 个旋钮集体蹦极。

## 复盘(本站带走的三句话)

- 「学习」= 调参数让 loss 变小,没有任何神秘成分;
- 梯度方向 = 下坡方向,大小 = 坡有多陡;
- 数据决定它能学到什么,训练只是找到那条最贴合数据的旋钮组合。

## 追问实录(金矿区,2026-10-19)

1. **「只有一个点 [(0.0, 1.04)] 也能试出 y=2x+1 吧?」** → **美妙的错**。实验:单点训练 loss 确实归零,但学到 `y = 0.000·x + 1.040`——w 根本没动!因为该点 x=0,loss 对 w 的梯度恒为 0,w 从没被「骂」过。两点(无噪声)才能钉死一条线(实测 2.000/1.000)。原则:**数据约束数 ≥ 旋钮数,解才唯一**(一个方程解不出两个未知数);**loss 归零 ≠ 学到真相**(欠定时有无穷组旋钮都能拿零分)。
2. **「y = 2x + 3z + 1 是不是就试不出系数了?」** → **惊喜的错,试得出**。多一个输入就多配一个旋钮(f = w1·x + w2·z + b),数值梯度各管各的。x、z 独立采样时实测学到 `(2.012, 2.998, 0.989)` ✓。**这就是神经元:加权求和**,S2 的预告;W(67×67)同理——67 个输入、每行 67 个旋钮的集团。
3. **教师翻车实录(比追问更值钱)**:实验二初版数据 z = 1.9 − x(x 与 z 完全联动),实测学到 `(1.439, 2.441, 2.042)`——预测全对、归因全错!这叫**特征共线**:输入总一起动,机器分不清功劳该记谁。教训:①设计实验/数据时输入要各自独立变动;②模型「预测对」不等于「理解对」——第 7 章压缩摘要「看起来对」陷阱的远房亲戚。
