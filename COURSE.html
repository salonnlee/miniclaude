支线 · 内功

神经网络补课

sidequest/ · 应学员需求插班
SQ从旋钮到反向传播🔥 进行中

「02 看不顺?那就离开主线,把神经网络的第一性原理亲手搭一遍——讲法浅显,内容不变样。」

  • S1 会学习的函数:旋钮(参数)、loss(打分)、数值梯度(量坡)、训练循环(下坡)——纯标准库 ✅
  • S2 神经元 = 加权求和 + 激活;多层与非线性的必要性(XOR 之役)🔥 已讲至第二幕 · 暂停消化
  • S3 反向传播 = 链式法则:手推梯度与数值梯度互证
  • S4 softmax + 交叉熵:grad = p − y 数值验证 → 回归主线 02,豁然开朗
交付:看得懂 02_neural_bigram.py 的每一行
▶🧠 S1 全景 · 一段话 + 一张图(下坡运动 × 训练循环)默认收起 · 点击展开

S1 整站只干一件事:教机器自己学会一个函数。模型是带旋钮的式子 ŷ = w·x + b(旋钮 w、b 就是「参数」);loss 用均方误差把「错得多离谱」压成一个数字——类比 CI 的红色失败数;数值梯度 [loss(w+H) − loss(w−H)] / 2H(H=0.00001)就是拿尺子量坡:符号指方向(往哪边拧 loss 会降)、大小给陡度(坡有多陡);训练则是循环执行 w −= LR·grad 顺势下坡——两百步后机器自摸出造数据的隐藏规律,学到 1.998x + 0.979(真相 y = 2x + 1,残差恰好等于噪声,理论不可再降)。途中的教训值回票价:LR 是步长,太大(LR=10)会一步跨过谷底、越蹦越高,loss 爆到 2.7×10²⁶;数据是教练,约束数 ≥ 旋钮数解才唯一——单个点训练 loss 照样归零,但 w 从没被「骂」过、纹丝不动(loss 归零 ≠ 学到真相);多维就多配旋钮,x、z 各分一个 w 各管各的,这正是 S2「神经元」的雏形;而两个输入若总一起动(特征共线),机器预测全对、归因全错——预测对 ≠ 理解对。

04 / PACT

教学契约

每章固定节奏:先教,后考,绝不突袭。

  1. 先讲概念——类比 + 图,不甩术语;
  2. 一起写代码——一次一小段,每段逐行讲清楚;
  3. 考考你——口头提问,或让你亲手写一小块(保证是教过的);
  4. 你运行、实验、瞎折腾;
  5. 复盘发散——这个设计在真实世界还有哪些做法。
