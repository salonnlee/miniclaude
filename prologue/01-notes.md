## 一句话

语言模型的唯一定义:**给定前文,给出下一个 token 的概率分布**——再花哨的模型也只是这一句话的不同实现。bigram 是最古老的实现:前文只看 1 个字符,概率靠数数。

## 核心概念

- **token**:文本最小切分单位。本课用字符级,词表 = 67(大小写 52 + 标点 + 空格 + 换行);
- **bigram 账本**:`counts[前字][后字]` 双层计数,归一化成概率表 `probs`;
- **采样 = 按概率抽签**(`random.choices` 加权);**贪心 = argmax** 永远选最大;
- **生成 ≠ 检索**:模型存的是分布,不是原文。复现原文的概率 ≈ 10⁻⁶⁰⁰(宇宙原子 ~10⁸⁰)。

## 代码地图(四段)

| 段 | 干什么 | 关键行 |

## 真实数据(可现场复验)

- `q → u` 概率 **100%**(2591/2591,莎翁笔下无一例外);
- `e → ' '` 29.2%;`'\n' → '\n'` 18.6%(剧本台词间全是空行);
- `'\n'` 当过 55 种字符的前字,累计 167,203 次。

## 学员追问实录(金矿区)

1. **defaultdict / Counter 是内置吗?** → Python 三层世界:语言内置(≈JS 全局)/ 标准库要 import(≈`node:` 模块)/ 第三方 pip(≈npm)。这俩住在 `collections`。
2. **zip / text[1:] 是什么?** → 切片 ≈ `slice()`;zip 是拉链配对,短的先停——`zip(text, text[1:])` 恰好产出全部相邻对。`zip(*x)` 的 `*` ≈ `...` 展开。
3. **为什么 range(600)?** → 输出长度的预算旋钮,一次循环吐一个字符。真模型里叫 **max_tokens**,同一个概念。
4. **为什么"回到开场符"?** → 兜底防「只活在语料末尾的字符」。学员当场审计出教师语病并促成修正:**「最后一个位置当不了前字」≠「末字符没当过前字」**——前者是位置,后者是字符类型;`'\n'` 到处出现,兜底在本语料是死代码,防的是"某字符全语料只出现一次且恰在末位"(反例语料 `"hello worldX"` 实验证实)。
5. **chars / weights 是什么值?** → `zip(*probs[cur])` 是转置:`[(' ',0.292),('r',0.126)..] → chars=(' ','r',..), weights=(0.292,0.126,..)`,JS 即 `pairs.map(p=>p[0])` / `map(p=>p[1])`。
6. **out 会是原文吗?** → 不会。模型里根本没存原文(训练完可删语料照常工作);原文是可能路径之一但概率 ~10⁻⁶⁰⁰;这就是"生成式模型":从学到的分布里**采样新样本**——Claude 每次回答措辞不同的根源。

## 考题与实测答案

- **Q1 词表为什么 67 不是 26?中文语料会怎样?** → 大小写、标点、空格、换行都是 token;换中文小说词表暴涨到数千,输出呈现"高频汉字组合"的形状。
- **Q2(动手)把抽签换成 argmax 会怎样?** → 学员实跑发现"全是空白字符,应该是 \n"——**判满分**。完整结论:**贪心世界有两个吸引子**,`'\n'` 自环坑(开场即入坑,一屏空白)和 `' '→t→h→e→' '` 循环圈(`"The the the the..."`),从任何字符出发必掉其一,原地复读到死。

## 复盘

- 统计规律 ≠ 知识:局部全对,整体全错;
- 同一张表,解码方式定生死:**贪心(argmax)= temperature 0 = 复读机的数学定义**;随机性不是缺陷,是解药(0.4 做成旋钮);
- 学员方法论:边界条件审计(corner-case auditing)——拿结论构造反例,第 5 章 Edit 工具同款思维。
