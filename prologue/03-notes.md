# 序章 0.3《前文加长:击穿数数表》· 讲义与追问实录

> 对应代码:`prologue/03_mlp.py` | 状态:✅ 完课(2026-10-27 一次开课;学员中后段快进模式连跳三题,考题挂账待补)

## 一句话

把前文窗口从 1 个字符拉到 3 个:数数表必须为每种 3 字符组合单开一行(67³ = 300,763 行,实测 94.9% 空户口),神经网络给每个字符发一张 16 维「含义向量」(C 表)、组合现场算——**知识从「每种上下文存一份」搬进「每个字符存一份」**,线性版 4,288 参数比 0.2 还少,加隐藏层的 MLP 版 dev 1.95,双杀 bigram(2.49)与 3-gram 数数表(2.54)。

## 核心概念

- **0.2 的 W 其实是两张表捏在一起**:每一行既是「字符的含义」又是「字符的打分器」;0.3 把两份工拆开——C 表(67×16)只管「你是谁」,W 矩阵(48×67)只管「3 份含义怎么合成打分」。只看 1 字时捏着没事,3 字一来必须拆;
- **身份证比喻(泛化 = 共享)**:数数表按组合发户口,组合指数爆炸、94.9% 空行;神经版按字符发身份证(恒 67 张),`hez` 没出现过,`h`/`e`/`z` 三张熟脸照样拼出分数——新组合 = 老简历的新搭配;
- **train/dev 切分首次入场**:前 90% 窗口学、后 10% 只考不学——处刑机关。背功与理解,考卷见分晓:数数表 train 1.56 / dev 2.54(背得越狠栽得越惨,尖刺概率赢小亏大),MLP train 1.94 / dev 1.95(分数靠懂组合挣的);
- **线性版的天花板**:W 按列切三块,logits = 三份独立评分相加,t/h/e 零交互;隐藏层(48→100 搅拌 + tanh 折弯 + 100→67 表决)让字符先开会再表决——NN2 老课兑现:**没有 tanh,两层线性塌成一层,白搭**;
- **初始化细节**:C/W 乘 0.01 → 初始分数全 0 → softmax 均匀 → 初始 loss = ln 67 = 4.2047(0.2 Q1 同题换马甲);W1 按 1/√48 缩初值,免得 tanh 开场就饱和。

## 学员追问实录(金矿区)

1. **「比较模糊,能不能画图」(前文 1→3 两条路怎么变)** → 换讲法三张图:①问题侧(qui 之后 [?] 几乎必是 c——新信息在组合里);②数数表变法(行单位从单字换成组合,67→300,763);③神经变法关键一步——先看穿 0.2 的 W「一张表干两份工」(含义+打分挤一行),3 字一来拆成 C(你是谁)+W(怎么合着打分),`hez` 没见过照样打分。教师自省:抽象表述(「你其实已经见过答案」)不如一张拆解图,重要概念一律图先行。
2. **押数:300,763 行里多少行有账?学员押 90%** → 开奖 5.1%。直觉错因是平均数错觉(457 万窗 ÷ 30 万行 ≈ 每行 15 笔账):文本是幂律的,热门行挤爆、长尾 28.5 万行零记录,平均数骗人。
3. **`RuntimeWarning: invalid value encountered in divide`(④段)** → `np.where` 三分支**全求值**再挑(≠ JS 三元惰性),被丢弃分支里的 0/0 照样发生;数值没错但过程不干净,修法 = 分母 `np.maximum(rows, 1)` 兜底。速查卡已增补(np.where / np.concatenate / str.count / np.stack 四条)。
4. **0.2 考题 Q2 预言「深网络大步翻车」——实测未兑现** → 严格梯度版(全部梯度用旧参数算完、再统一更新)lr=1.0 跑满 30000 步不炸,只在谷底两侧振荡(2.19↔2.23)。但备课首版真炸过:那版把顺序写反(先更新 W、再用新 W 反传 dh),大步长下自激滚雪球 → exp 溢出 → inf → nan。结论改写:**「先反传完、再更新」不是仪式感,是语义**——用更新后的参数给还没走完的梯度当桥,等于让它踩着挪动过的地面量坡。预言的另一半(真深度会翻)留给后续课再验。

## 复盘与预告

- **处刑定性**:数数表死于斜率——每加一个字符前文,表 ×67、空户口率飙升、手艺(回退/插值/λ)全部重调;神经版加一个字符,C 表不动、W 宽 16 列。GPT 的 2,048 上下文,只有一条路走得通。行家的插值手艺在 457 万字符的小语料上仍有 1.79 的余勇——小数据上「记忆+平滑」能打,恰是历史现场:Bengio 2003 论文里 MLP 对阵的就是平滑 N-gram,数据规模上去后神经路线全面反超;
- **0.2→0.3 的会师反转**:0.2 里数数表是理论最优、神经版追平;0.3 里数数表需要行家手艺续命,神经版裸考双杀——learn it all(连「怎么组合」也是学出来的)对 fix it all(每级手动修补)的胜势,从这课开始;
- **0.4 预告**:模型会接龙了,但采样永远挑最大概率——安全牌复读机。给它一支温度计:logits 除以 T 再 softmax,T 高赌性大、T 低求稳,0.1 抽签台的「贪心掉坑」在公式里找到归宿;top-k 顺手带上。
